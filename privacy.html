Политика конфиденциальности

Действует с 30 июня 2026 года

1. Основные положения

1.1. Настоящая Политика описывает, как Element Rust собирает, использует и защищает данные Пользователей.

1.2. Регистрируясь на сайте или на игровом сервере, подключаясь к игре или совершая платёж, Пользователь даёт безоговорочное согласие на сбор и обработку своих данных согласно этой Политике.

2. Собираемые данные

2.1. Автоматически собираемые данные: IP-адреса и история их изменения; уникальные идентификаторы мобильного устройства (Device ID, рекламные идентификаторы); идентификатор игрового аккаунта, данные привязанных платформ (Google Play, Apple ID и т.д.), никнейм; данные телеметрии и логи игрового процесса (действия, статистика); логи внутриигрового чата и голосовой связи.

2.2. Данные, предоставляемые Пользователем: адрес электронной почты (при регистрации или покупке); дата рождения (при регистрации, для подтверждения соответствия возрастным требованиям использования Сервисов); данные обращений в службу поддержки.

2.3. Администрация не собирает и не обрабатывает данные банковских карт. Все операции проводятся на стороне сертифицированных платёжных агрегаторов.

3. Цели сбора данных

Данные используются исключительно в следующих целях: идентификация Пользователя и предоставление доступа к аккаунту и покупкам; обеспечение безопасности и работа античит-систем (Device ID и IP собираются для выявления обхода блокировок); аналитика и улучшение качества работы серверов и мобильного приложения; модерация внутриигрового поведения (анализ логов на предмет нарушений); подтверждение соответствия Пользователя минимальным возрастным требованиям.

4. Передача данных третьим лицам

4.1. Администрация не продаёт данные Пользователей.

4.2. Данные могут быть переданы: платёжным системам (только данные, необходимые для проведения транзакции); сторонним античит-сервисам и базам данных игровых серверов в случае выявления использования запрещённого ПО (читы) для формирования глобальных списков блокировок; правоохранительным органам по обоснованному и законному запросу.

5. Сроки хранения данных

5.1. Данные активных Пользователей хранятся в течение всего времени работы Проекта.

5.2. Исключение для нарушителей: данные Пользователей, заблокированных за использование читов, багов или деструктивное поведение (Игровой ID, IP, Device ID), хранятся бессрочно в целях защиты Проекта от повторного доступа данных лиц. Это является законным интересом Администрации.

6. Использование файлов Cookie

Сайт использует файлы cookie для поддержания сессий (авторизации), сохранения предпочтений и сбора обезличенной статистики посещаемости.

7. Права Пользователя

7.1. Пользователь имеет право запросить удаление своего профиля на сайте (через обращение в поддержку: [email будет добавлен]).

7.2. Удаление профиля не влечёт за собой удаление записей о блокировках (банах) из базы данных игрового сервера.

8. Безопасность

Администрация предпринимает коммерчески обоснованные технические меры для защиты данных от несанкционированного доступа. Однако ни один способ передачи данных через Интернет не является абсолютно безопасным, и Администрация не может гарантировать стопроцентную защиту.
